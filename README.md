# Monti Keopi Website v2

This folder is a finished static site. No build step.

## Put it on Cloudflare Pages

1. Unzip so you can see index.html in this folder.
2. Cloudflare dashboard → Workers & Pages → the project that already has monti-keopi.com.
3. Create deployment → Direct Upload.
4. Drag this folder (the one that contains index.html, not the zip).
5. Publish. The custom domain updates if it is already attached to this project.

## What is in this version

- No drink prices and no licensing fee table
- Homepage card button says Explore
- Each outlet has its own photo
- Licensing line: Estimated basic setup starting RM65k
